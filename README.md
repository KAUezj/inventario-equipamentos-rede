
# 🌐 Inventário de Equipamentos de Rede

## 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver e organizar
um inventário de equipamentos de rede, permitindo
identificar, registar, consultar e controlar os
equipamentos existentes numa infraestrutura informática.

O inventário pretende facilitar a administração da rede,
melhorar a organização dos ativos tecnológicos e apoiar
as atividades de manutenção e gestão da infraestrutura.

## 🎯 Objetivos

- Identificar os equipamentos de rede existentes.
- Registar as características técnicas dos equipamentos.
- Organizar os endereços IP e MAC.
- Identificar a localização física dos equipamentos.
- Controlar o estado operacional dos equipamentos.
- Facilitar a manutenção e atualização do inventário.
- Documentar o trabalho através do GitHub.

## 🖥️ Equipamentos Abrangidos

O inventário poderá incluir:

- Routers
- Switches
- Firewalls
- Access Points
- Servidores
- Bastidores de rede
- Outros equipamentos de comunicação.

## 📋 Dados Registados

Para cada equipamento serão considerados os seguintes dados:

| Campo | Descrição |
|---|---|
| ID | Identificador do equipamento |
| Equipamento | Nome ou tipo de equipamento |
| Marca | Fabricante |
| Modelo | Modelo do equipamento |
| Número de Série | Identificação do fabricante |
| Endereço IP | Endereço de gestão |
| Endereço MAC | Identificador de rede |
| Localização | Local onde está instalado |
| Estado | Estado operacional |
| Observações | Informação complementar |

## 🛠️ Tecnologias e Ferramentas

- GitHub: armazenamento e versionamento do projeto.
- Git: controlo de versões.
- CSV: organização dos dados do inventário.
- Markdown: documentação do projeto.

## 🔄 Metodologia

1. Levantamento dos equipamentos de rede.
2. Recolha das informações técnicas.
3. Identificação e classificação dos equipamentos.
4. Registo dos dados no inventário.
5. Organização da documentação.
6. Atualização e manutenção dos registos.

## 🔐 Segurança

Os dados de acesso, palavras-passe, chaves privadas
e outras informações confidenciais não devem ser
incluídos no repositório.
