# PROPOSTA DE PROJETO
## Inventário de Equipamentos de Rede

**Área:** Informática e Administração de Redes

**Projeto:** Inventário de Equipamentos de Rede

**Autor:** Kaue Viana da Silva, Kauã Viana da Silva

**Data:** Novembro de 2026

---

## 1. Introdução

Atualmente, as infraestruturas informáticas dependem de diversos equipamentos de rede que asseguram a comunicação entre computadores, servidores e outros dispositivos.

A falta de um inventário organizado e atualizado pode dificultar a identificação dos equipamentos, a localização física, a manutenção e a gestão da infraestrutura.

Neste contexto, propõe-se a realização de um projeto de inventário de equipamentos de rede, com o objetivo de centralizar e organizar toda a informação técnica relevante.

## 2. Problema identificado

A gestão de equipamentos de rede exige informação atualizada sobre os dispositivos existentes, as suas características técnicas, os endereços IP, os endereços MAC e a respetiva localização.

Quando estes dados não estão devidamente organizados, podem surgir dificuldades na manutenção, resolução de problemas e controlo dos equipamentos.

O projeto pretende responder a estas necessidades através da criação de um inventário estruturado.

## 3. Objetivo geral

Desenvolver um inventário organizado de equipamentos de rede que permita identificar, registar, consultar e controlar os dispositivos existentes numa infraestrutura informática.

## 4. Objetivos específicos

- Identificar os equipamentos de rede existentes.
- Registar marca, modelo e número de série.
- Documentar os endereços IP e MAC.
- Registar a localização física dos equipamentos.
- Identificar o estado operacional dos dispositivos.
- Organizar os dados num formato estruturado.
- Criar documentação técnica de apoio.
- Utilizar o GitHub para armazenar e controlar as versões do projeto.

## 5. Âmbito do projeto

O inventário poderá abranger os seguintes equipamentos:

- Routers;
- Switches;
- Firewalls;
- Pontos de acesso Wi-Fi;
- Servidores;
- Bastidores de rede;
- Outros equipamentos de comunicação.

## 6. Metodologia

O projeto será desenvolvido através das seguintes etapas:

**Fase 1 – Levantamento:** identificação dos equipamentos existentes.

**Fase 2 – Recolha de dados:** obtenção das características técnicas de cada equipamento.

**Fase 3 – Organização:** classificação e estruturação da informação recolhida.

**Fase 4 – Registo:** introdução dos dados no inventário.

**Fase 5 – Documentação:** elaboração dos documentos técnicos e explicativos.

**Fase 6 – Versionamento:** armazenamento dos ficheiros no GitHub e registo das alterações.

## 7. Ferramentas utilizadas

- GitHub – alojamento e organização do repositório.
- Git – controlo de versões.
- Markdown – elaboração da documentação.
- CSV – armazenamento estruturado dos dados do inventário.

## 8. Resultados esperados

No final do projeto pretende-se obter:

- Um inventário organizado dos equipamentos de rede.
- Uma base de informação técnica centralizada.
- Uma identificação clara dos equipamentos.
- Uma documentação técnica estruturada.
- Um repositório GitHub com histórico de alterações.
- Uma solução que permita futuras atualizações.

## 9. Segurança da informação

A informação recolhida deverá ser tratada de forma responsável. Não deverão ser publicados dados confidenciais, palavras-passe, chaves privadas ou credenciais de acesso.

Caso o inventário contenha informações sensíveis da infraestrutura, o repositório deverá ser privado e o acesso limitado a pessoas autorizadas.

## 10. Conclusão

Este projeto pretende melhorar a organização e a gestão dos equipamentos de rede através da criação de um inventário estruturado e de documentação técnica.

A utilização do GitHub permitirá manter os documentos organizados, controlar as alterações e preservar o trabalho desenvolvido.

O projeto poderá ser futuramente ampliado através da implementação de uma aplicação de gestão de inventário.
